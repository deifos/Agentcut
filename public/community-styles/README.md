# Community editing styles

Each folder is one style from the community library, listed after review. See
[docs/community-styles.md](../../docs/community-styles.md) for how submissions work.

A folder holds only `style.json`, `PROMPT.md`, `poster.jpg` and (optionally) `demo.mp4`.
Run `npm run community:check` after any change; the site build fails on an invalid folder.
