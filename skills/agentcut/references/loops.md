# Motion loops, brand palettes and variety

Agentcut ships a library of 44 seamless **motion loops** (all live at agentcut.synteq.app/loops),
each a pure function of time on a 12 s cycle (the frame at 12 s is the frame at 0 s), drawn from the
brand's colours. Use them so no video sits on a dead flat colour, and so every video looks different.

## Use one

- **As a clip** (the user can edit it in the inspector): component `motion-loop` on a track under the
  content, e.g. `{ "component": "motion-loop", "props": { "loop": "dot-wave", "tone": "light",
  "accent": "#f97316", "accent2": "#ec4899", "seed": 7 } }`. `agentcut_components` with
  `id: "motion-loop"` lists every loop.
- **Inside a scene** (behind a cinematic Stage, on a card, in a split):
  `import { LoopCanvas } from "agentcut/components"` →
  `<LoopCanvas loop="iso-cubes" accent={brand} accent2={brand2} tone="dark" seed={3} />`. Without
  `width`/`height` it is frame-sized and stretches to its parent, so use it full-frame (or in a box
  with the frame's aspect). In any other box pass that box's size in px, e.g. on a `Plane` (a great
  card in 3D): `<Plane width={800} height={500}><LoopCanvas loop="dot-wave" width={800} height={500} /></Plane>`;
  then it draws at exactly that size and never distorts. Put it first inside `<Stage>` instead of
  `<Backdrop>`, or on a Plane far behind the devices (`z: -800`) so it parallaxes with the camera.
- Props: `tone` `dark` (deep brand-tinted background, brand motif), `accent` (solid brand colour,
  ink or paper motif), `light` (paper background, ink motif, brand as the second colour); `speed`
  (seamless at any speed inside a clip; a clip that repeats needs length × speed to be a multiple of
  12 s); `seed` (another layout of the same loop); `transparent` (shapes over footage or a Stage);
  `blur` (motion-blur sub-frames in captures and exports, 4 default for both `motion-loop` and
  `LoopCanvas`, 8 for fast loops, 1 for none; the live preview always draws 1). An unknown `loop` id
  warns in the console and falls back to `gradient-blobs`.

## The library

Backgrounds: `perspective-grid` (grid floor streaming to a glowing horizon: tech, retro, gaming),
`dot-wave` (dots swelling in a diagonal wave: calm product), `flow-lines` (breathing signal lines: data,
finance), `gradient-blobs` (living mesh gradient: the safe premium backdrop), `stripes-scroll` (bold
diagonal stripes: loud promos, sport, sales), `concentric-pulse` (rings on the beat: reveals, music),
`checker-twist` (tiles twisting in a wave: playful, design), `halftone-sweep` (halftone with light
bands: editorial, print), `terrain-ridges` (ridgelines rolling in: moody, music, night), `starfield-warp`
(warp streaks: hype, speed), `bokeh-drift` (soft rising lights: dreamy, lifestyle, behind devices),
`iso-cubes` (isometric blocks rising: infrastructure, dev tools), `ribbon-weave` (thick waving
ribbons: fluid, consumer), `tile-mosaic` (tiles flipping colour: marketplaces, many features).

Symmetry: `kaleidoscope` (8-way mirrored drift: music, festivals, hypnotic), `mandala-bloom` (petal rings
turning both ways: wellness, elegant), `spirograph` (a pen tracing a spirograph: precision, design),
`mirror-tiles` (four-way mirrored arc tiles turning: design, architecture), `radial-burst` (retro sunburst:
announcements, sales, pop).

Morphing: `shape-morph` (circle → square → triangle → star with squash: transformation, versatility),
`morph-grid` (a grid of shapes morphing in a wave: systems, modular), `shape-shuffle` (three shapes
hopping and becoming each other: choices, onboarding), `metaballs` (liquid blobs merging: fluid, AI).

Games: `snake-game` (pixel snake eating food: gaming, retro, 'level up'), `falling-blocks` (blocks stack and
clear: building, organizing), `pong` (paddles rallying: back-and-forth, versus), `life-gliders`
(Game of Life gliders: code, dev tools, emergence).

Physics: `newtons-cradle` (momentum, cause and effect), `clock-gears` (automation, workflows),
`liquid-fill` (progress, growth, drinks), `domino-wave` (chain reactions, automation).

Generative: `vortex` (particles spiralling into a core: AI, gravity), `lissajous-trail` (a comet tracing
a Lissajous figure: signals, elegance), `bubble-pop` (bubbles rising and popping: playful, social).

Shapes (one centered subject, use `transparent` over other layers): `orbit-rings` (AI, platforms),
`morph-blob` (assistants, organic), `bouncing-ball` (playful, loading), `spinner-petals` (blooming,

(products, blocks), `dna-helix` (science, health, data), `pie-burst` (analytics, sharing),
`wave-bars` (audio, voice, podcasts).

## "Generated by an agent" effects

- `dot-trace-title` (component): a headline traced in dots by a scan line that resolves into the type.
  For AI features, agents, "built for you" moments. Lines take `*starred*` words or a `*starred phrase*`
  for the accent; `size` is a share of the frame's short side (× 0.9), `dot` is px at 1080p (scales).
- `GenerateReveal` (scenes, from `agentcut/components`): a screenshot or photo builds itself the way an
  agent would generate it: dotted wireframes per UI block (with the agent's cursor), a dotted fill made of
  the image's own pixels, then the real pixels resolve block by block, with an optional agent log. When
  the build ends (`from + duration`) the whole image cross-fades in over ~10 frames, so the end state is
  exactly the screenshot, including areas no box covers.
  `<GenerateReveal src={asset("assets/app.png")} width={1440} height={900} from={0} duration={120}
  boxes={[[0,0,0.16,1],[0.18,0.1,0.79,0.08], …]} log={["Laying out the sidebar", …]} accent={brand} />`
  - `width`/`height`: the box in px; the image covers it (crop like `object-fit: cover`). Inside a
    cinematic `Screen` (as its children) the Screen's `width` and `aspect` define the box: pass
    `width={W} height={W / aspect}` with the same values, or the build won't fill the screen.
  - `boxes`: the UI's blocks `[x, y, w, h]` as fractions of the image in build order; measure them from
    the image like hero regions (values are clamped to 0–1). Leave out for photos (one block).
  - `mode`: `"ui"` (wireframe → dots → pixels) or `"image"` (tone sketch → colour dots → photo).
  - `dot` (pitch in box px, default 9), `accent`, `log` (one line per block reads best; Geist Mono, loaded
    and held for you), `logPosition`, `radius`, `background`.
  - `resolution`: pixel ratio of the dots canvas, default 2 in renders/exports (sharp under a camera
    push-in) and 1 in the live preview; lower it for very large boxes. A Plane's blurred and reflected
    copies draw it at 0.5 automatically.
  - The dotted fill reads the image's pixels, so it needs a same-origin asset (`asset(…)`) or a CORS-enabled
    URL. Otherwise it logs a warning and builds without the dotted fill (wireframes, log and pixel reveal
    still play); it never stops the export. A missing image still fails the render (its `<Img>`).
  Use it once per video, as the hook or the "watch it build" moment.

## Brand palette first

1. Find the brand colours before you design: the logo, the product UI in the screenshots, the
   website, `project.json`. Write them in notes.md: primary, secondary, and the brand's own dark and
   light (often in the UI).
2. Build every look from them: `accent` = primary, `accent2` = secondary (or a complement: the primary's
   opposite hue at lower saturation), tone per shot. Text on the loop: ink on `light`, paper on `dark`,
   whichever reads on `accent`.
3. Two or three colours per frame, never a rainbow. One accent moment per shot.

## Variety (every video, every take)

- Never the same loop twice in a row, and at least three different loops or looks in a 15–30 s video.
- Alternate tones between shots (dark → light → accent …) or hold one tone and vary the loop: decide,
  then write the rotation in the shot list.
- Change `seed` when you reuse a loop, and pick loops by mood (the list above), not by habit: before
  you choose, write the two you used in the last video in notes.md (if any) and pick others.
- Mix layers: a background loop, the hero (screens, devices, type), and sometimes a shape loop as an
  accent (transparent, small, in a corner or behind a title) or kinetic shapes on a Plane in depth.
- Shape loops are great section openers and end cards: a centered shape with the brand name below it.

## Write a new loop (when nothing fits)

Write it in the scene as a draw function and pass it to `LoopCanvas`:

```tsx
import { LoopCanvas, type LoopDraw } from "agentcut/components";
const sparks: LoopDraw = (ctx, w, h, t, P, M, seed) => {
  const u = h / 100;
  for (let i = 0; i < 60; i++) {
    const p = M.phase(t, 3, M.rand(i, seed));          // a 3 s cycle, staggered per element
    ctx.fillStyle = M.rgba(i % 4 ? P.fg : P.fg2, 1 - p);
    ctx.beginPath();
    ctx.arc(M.rand(i, 1) * w, h - p * h, u * (0.5 + 2 * M.rand(i, 2)), 0, M.TAU);
    ctx.fill();
  }
};
// <LoopCanvas loop={sparks} accent={brand} tone="dark" />
```

Rules that keep it seamless and premium:
- The frame depends on `t` only: no `Math.random`, `Date` or state between frames; randomness from
  `M.rand(i, salt)`. Every period divides 12 (1, 1.5, 2, 3, 4, 6, 12) via `M.phase(t, period, offset)`;
  scrolls move whole pattern repeats per period; anything indexed by cycle wraps with `M.mod`.
- Colours only from `P` (`bg fg fg2 mid accent accent2 paper ink`) with `M.rgba` / `M.mixColor`.
- Sizes from `u = h / 100` (shapes: `Math.min(w, h) / 100`), counts from `w`, so it works in wide and
  mobile.
- Designed motion: eases from `M.ease` (`outBack`, `spring`, `inOutCubic`…), anticipation and
  overshoot, short holds; constant speed only for scrolls and streams. `M.win(p, a, b)` chains
  wind-up, action and settle inside a cycle; put the loop point inside a hold.
- Keep a frame under ~2,000 primitives; glows are radial gradients, never `ctx.filter`.
- Check it: capture frames inside one cycle and either side of the 12 s point.

A loop worth keeping for other videos: save it in the workspace library
(`library/loops/<name>.ts`, exporting the draw function) with a one-line description at the top, and
list it in `library/loops/README.md`. Later videos import it by relative path from their scene:
`import { sparks } from "../../../library/loops/sparks";` (scenes live in `projects/<slug>/scenes/`).
Read `library/loops/README.md` before writing a new loop: one may already exist.
