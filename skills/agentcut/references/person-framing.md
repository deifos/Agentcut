# Person centering and following

Use agentcut_frame_person for an explicit request to center or keep a visible speaker centered. Do not install detection packages, upload frames, use image APIs or guess a crop from a screenshot. An aspect-ratio change alone does not authorize framing.

1. Call agentcut_status. Pass the target variant and video clip IDs. The tool defaults to selected clips, or the sole visible, unlocked video clip. With several candidates, select the intended clip or ask the user. Maximum eight clips; all must succeed before any path is saved.
2. For ordinary keep-centered requests, use action:center and mode:follow (the default). The full displayed source range is sampled at no more than 0.5-second source intervals, including the first and last source frame. Trim, playback speed, source display dimensions, rotation and pixel aspect ratio are respected. Up to 10 minutes of source time per clip and 1,800 samples per call are supported. Split longer shots or process fewer clips; the tool does not silently inspect only part of a clip. mode:static explicitly requests one fixed crop from nine samples.
3. Follow mode retains one spatially continuous face, checks position/size changes, applies a dead zone and low-pass smoothing, and bounds the crop inside the source. It holds the last crop during detection loss of up to 1.5 seconds. It rejects multiple faces, long loss, weak coverage, large picture changes, abrupt subject changes and crop jumps. These return structured status and next steps, without applying a partial path. Ask for a clearer or shorter shot, or a wider format. Do not switch people or guess after failure.
4. Results report coverage, held samples, keyframe count and boundsLimited. Narrow output or source edges can limit ideal centering and headroom; no detail is restored. Source frames remain local in a CPU worker; the conversational agent still uses tokens, but detection makes no LLM/image API calls. Model/runtime files come from Agentcut.
5. Preview and export evaluate the same persisted crop path at source time: trimStart/fps + localFrame/fps * playbackRate. Seeking is deterministic. Timing, clip box, grade and other variants remain unchanged. Style camera motion is suspended while framing is set. The crop/path replaces cover/contain fitting inside the existing box. Original project or library videos are supported; scene-embedded video and cursor overlays are not.
6. Review captures at the start, moving sections and end in the target variant. Detection is sampled, not frame-by-frame, and does not recognize identity. It can miss a short cut, face or fast movement between samples. Large picture/face jumps are treated as possible cuts, not guaranteed scene detection. The tool asks for shot splits rather than selecting an identity or crossing an uncertain cut.
7. Reset with action:reset and the same clips/variant. It restores prior crop and path overrides and preserves later unrelated edits. Normal studio Undo restores the previous timeline. After an unconfirmed save or conflict, inspect the timeline before retrying. Update and restart the helper/runtime before using this new field; do not restart during the user's live work.

Persisted field: variants.<variant>.framing contains crop (upright source fractions), optional path entries {seconds,crop} at absolute source times, and before/beforePath reset metadata. Prefer the tool over hand edits. Do not copy a path to another source/aspect ratio without analysis. Later trim changes outside the analyzed source range hold the end crop; rerun the tool to analyze any newly exposed source.
