# Transcription providers

Use the built-in operation. Do not install a provider SDK, ask for keys in chat, or write upload scripts.

- `agentcut_transcription_options` lists preferred provider, configured status, models, capabilities and jobs, never credentials. Local Whisper is the initial default. Adding a cloud key does not select it. The user selects a preference under Transcription in either editor view.
- `agentcut_transcribe` accepts `path`, optional `project`, `provider`, `model`, `language`, `speakerLabels` and a unique optional `job` ID. Use the preference unless the user explicitly asks for an override, such as `provider: "local"`. Never silently switch after an error. For unconfigured providers ask the user to open settings; never ask them to paste a key in chat.
- Local Whisper retains tiny/base/small models and word timings. Language defaults to en; it needs an explicit language code and does not supply speaker labels. Filler recognition is not guaranteed. Its files stay local, though model downloads may be needed.
- AssemblyAI uses the user's API key in the helper. Audio is extracted locally, then uploaded to AssemblyAI. Provider charges and provider data handling apply. It uses Universal-2 and always requests `disfluencies: true` for editing. That model's filler support is English only; other languages and automatic language detection do not guarantee filler recognition. Speaker labels are optional. A key does not imply permission to run unsolicited paid test jobs.
- Results use seconds (`start`, `end`) and project frames (`fromFrame`, `toFrame`) from the original source, not edited timeline positions. Preserve trims and map words through cuts. Results include provider/model/options/source provenance, a cache key, segments and speaker labels when available. Cached results are separated by source content, provider, options and fps. Raw recognized filler words and their timings are retained. A transcript that omits fillers is not evidence that the audio was edited.
- Pass a unique `job` ID if you need progress or cancellation. Discover stages with `agentcut_transcription_options`, cancel with `agentcut_cancel_transcription`. Transcription settings also shows active jobs and Cancel. Cancellation stops local processing or cloud polling; remote work and charges may already have begun. No other provider is used as fallback.
- Listen before making silence/filler cuts. ASR timings and words can be wrong, especially with music, overlap, accents or poor audio. Do not equate a cleaner text result with edited speech.

Implementation extension points are separate: `src/studio/transcription/registry.ts` for recognition and `src/studio/voice/registry.ts` for synthesis. An adapter owns metadata, capabilities and provider calls. Both use helper-only provider settings/secret storage. Adding a synthesis provider does not make it a transcription provider.
